# PokéMart - Cyber Edition 🎮

A futuristic Pokémon card marketplace built with Next.js, featuring stunning animations, cyberpunk aesthetics, and an immersive shopping experience.

## ✨ Features

- **Immersive UI**: Cyberpunk-inspired design with animated backgrounds
- **Animated Sprites**: Gen 5 pixel art animations on hover
- **Type Filtering**: Filter cards by Pokémon type
- **Search Functionality**: Quick search across all cards
- **Shopping Cart**: Full cart management with quantity controls
- **Detail Modal**: Expanded view with stats and descriptions
- **Responsive Design**: Works seamlessly on all devices

## 🚀 Quick Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/jashmhta/pokemon-marketplace)

### Manual Deployment Steps:

1. Visit [Vercel](https://vercel.com/new)
2. Import your GitHub repository: `jashmhta/pokemon-marketplace`
3. Vercel will auto-detect Next.js settings
4. Click **Deploy**
5. Your app will be live in minutes! 🎉

## 🛠️ Local Development

```bash
# Install dependencies
npm install
# or
pnpm install

# Run development server
npm run dev
# or
pnpm dev

# Open http://localhost:3000
```

## 📦 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: CSS + Canvas API
- **Deployment**: Vercel

## 🎨 Design Features

- Canvas-based animated background with particles and hexagons
- Gradient overlays and glassmorphism effects
- Smooth transitions and hover states
- Pokéball capture animation
- Retro pixel art sprites from PokeAPI
